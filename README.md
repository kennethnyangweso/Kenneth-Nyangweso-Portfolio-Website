## 🔧 Local Development

To run this website locally:

```bash
# Clone the repository
git clone https://github.com/kennethnyangweso/kennethnyangweso.github.io.git

# Navigate to the folder
cd kennethnyangweso.github.io

# Open in browser
open index.html  # Mac
start index.html # Windows

```
